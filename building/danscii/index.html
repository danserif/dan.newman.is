Credits / Instructions

D@N5C1I was built by Dan Newman (me) using Cursor and Claude Code / Design.

The download is a folder [danscii.zip] with your settings in a [index.html] file alongside the image you chose. When you open the file on your computer, a temporary image chooser is required to preview your ASCII. You can delete that section when adding the files to your site, and you’re free to customise D@N5C1I as needed.

If you use D@N5C1I, please credit me and link to dan.newman.is/building/danscii — thanks! \m/
